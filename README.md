# Logix – Cognitive Puzzle Suite

Logix is a lightweight, offline‑first desktop application built with JavaFX. It consolidates multiple classical logic mini‑games into a single modular launcher, designed for rapid 3‑minute cognitive engagement sessions. The project demonstrates strong application of Object‑Oriented Programming principles and clean MVC architecture.

## 🚀 Features
- Multi‑game launcher with smooth scene switching
- Offline dual modes: pass‑and‑play multiplayer & AI opponents
- Local score tracking using Java File I/O
- Responsive UI styled with JavaFX CSS and FXML
- One‑click resets for fast gameplay loops
- Defensive validation and exception handling for robust performance

## 🛠️ Tech Stack
- Java (JDK 17/21)
- JavaFX, FXML, CSS
- Scene Builder for UI prototyping
- Maven for build lifecycle automation
- IntelliJ IDEA / VS Code for development
- GitHub for version control and collaboration

## 📐 Architecture
- MVC pattern: clean separation of Model, View, Controller
- OOP pillars: Encapsulation, Inheritance, Polymorphism, Abstraction
- Modular design enabling easy expansion with new mini‑games

## 🎯 Vision
Logix replaces passive scrolling with active cognitive workouts, offering a frictionless, offline, and modular ecosystem. It is designed to be lightweight, reliable, and extensible for future enhancements.
